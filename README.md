##  السؤال / المشكلة
* **السؤال الأساسي:** [أي هدف/كوكب خارجي عنده أفضل تغطية رصدية؟]
* **السياق:**[المشكلة هي توجد عدة كواكب خارجية لا نعلم أيها يملك أفضل تغطية رصدية,الهدف من حل المشكلة هو الوصول لأفضل نتيجة علمية ممكنة ]
  ولاحظنا عند اكتمال التحليل ان **RES-5 هو الكوكب الخارجي الذي يتمتع بأفضل تغطية رصدية، بمجموع يتجاوز 4,000 ساعة من الرصد — أي نحو ضعف الهدف التالي الأفضل (CoRoT-2). ما يجعله المرشح المثالي لأي دراسة علمية متعمقة (مثل تحليل الغلاف الجوي، وتغيرات توقيت العبور TTV، ومطيافية العبور).**
